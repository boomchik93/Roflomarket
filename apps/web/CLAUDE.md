# web

Интерфейс Roflomarket. React, Vite, TypeScript (strict).

## Правила

- Клиент не считает цены, выплаты и балансы. Все числа приходят от gateway. Клиент только форматирует.
- Денежные значения приходят строкой. Для арифметики отображения используй `bigint`, не `number`.
- Вёрстку делай по макету Figma через агента `figma-implementer`. Цвета, отступы и шрифты бери из токенов, не вписывай значения в компоненты.
- Перед новым компонентом проверь, нет ли подходящего в `src/components`.
- Живые обновления цен идут по WebSocket от gateway. Не опрашивай REST по таймеру.
- К engine напрямую клиент не обращается.

## Команды

Из корня репозитория:

```bash
npm run dev -w apps/web
npm run lint -w apps/web
npm run typecheck -w apps/web
npm test -w apps/web
npm run build -w apps/web
```

## Проверка

Изменение интерфейса проверяй в браузере через Playwright MCP: открой страницу, сделай действие, посмотри результат. Прошедший typecheck не доказывает, что экран работает.
