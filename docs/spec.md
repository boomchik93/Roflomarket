# Спецификация рынка

Статус: черновик. Формулы и открытые вопросы должна подтвердить команда до начала работы над engine.

## Термины

- **Цент** — минимальная единица игровой валюты. 1 монета = 100 центов. Все суммы в системе — целые числа центов.
- **Рынок** — вопрос с двумя исходами: YES и NO.
- **Доля** — право получить 1 цент, если исход наступил. Доли бывают YES и NO.
- **Полный набор** — 1 доля YES и 1 доля NO. Всегда стоит ровно 1 цент: один из исходов наступит.
- **Пул** — запас долей рынка: `y` долей YES и `n` долей NO.

Реальных денег в системе нет. Ввод и вывод средств не предусмотрен.

## Цена

Рынок работает как автоматический маркет-мейкер с постоянным произведением: `y * n = k`.

Вероятность YES: `P(YES) = n / (y + n)`. Вероятность NO: `P(NO) = y / (y + n)`. Сумма равна 1.

Для отображения цена считается в базисных пунктах: `n * 10000 / (y + n)`.

## Создание рынка

Системный счёт вносит ликвидность `L` центов. Пул получает `y = n = L`, начальная вероятность 50%. Максимальный убыток системного счёта по рынку не превышает `L`.

## Покупка

Пользователь покупает YES на сумму `a` центов.

1. На `a` центов создаётся `a` полных наборов. Они идут в пул: `y + a`, `n + a`.
2. Пул отдаёт пользователю столько YES, чтобы произведение вернулось к `k`.

```
n' = n + a
y' = ceil(k / n')
shares = (y + a) - y'
```

Покупка NO симметрична: `y` и `n` меняются местами.

Пример: `y = n = 1000`, `a = 100`. Тогда `n' = 1100`, `y' = ceil(1000000 / 1100) = 910`, `shares = 190`. Новая вероятность YES: `1100 / 2010 ≈ 54,7%`.

## Продажа

Пользователь продаёт `s` долей YES и получает `a` центов.

1. Доли идут в пул: `y + s`.
2. Пул погашает `a` полных наборов и отдаёт `a` центов так, чтобы `(y + s - a) * (n - a) >= k`.

```
S = y + s + n
D = S * S - 4 * s * n
a = floor((S - ceil_sqrt(D)) / 2)
```

Продажа NO симметрична.

## Округление

Округление всегда в пользу пула: пользователь получает долей и центов не больше точного значения. После каждой операции `y' * n' >= k`. Код проверяет это условие перед фиксацией транзакции и отклоняет сделку при нарушении.

Произведения `y * n` и `S * S` могут не поместиться в `int64`. Считай их в 128 битах (`math/bits` или `math/big`).

## Расчёт рынка

Рынок закрывается с исходом YES или NO. После закрытия сделки запрещены.

- Каждая доля победившего исхода выплачивает владельцу 1 цент.
- Доли проигравшего исхода сгорают.
- Остаток обеспечения рынка возвращается на системный счёт.

Расчёт идемпотентен: повторный вызов ничего не меняет.

## Ledger

Каждое движение денег — пара проводок: списание с одного счёта и зачисление на другой.

Счета: счёт пользователя, счёт обеспечения рынка, системный счёт.

- Покупка: пользователь → обеспечение рынка, `a` центов.
- Продажа: обеспечение рынка → пользователь, `a` центов.
- Выплата: обеспечение рынка → пользователь.
- Стартовый бонус и ликвидность: системный счёт → пользователь или обеспечение рынка.

## Инварианты

Эти условия проверяются property-тестами и не должны нарушаться никогда.

1. Сумма всех проводок ledger равна нулю.
2. Баланс пользователя не меньше нуля.
3. Для открытого рынка `y > 0`, `n > 0`, и `y * n` не убывает.
4. Обеспечение рынка не меньше максимальной возможной выплаты: `max(все выданные YES, все выданные NO)`.
5. Покупка на `a` с немедленной продажей полученных долей возвращает не больше `a`.
6. Повтор операции с тем же idempotency key не меняет состояние.
7. После расчёта рынка его обеспечение равно нулю.

## Открытые вопросы

- Размер стартового бонуса и ликвидности `L`.
- Кто и как закрывает рынок: автор, модератор, голосование.
- Отмена рынка: как возвращать средства, если рынок признан некорректным.
- Комиссия со сделки: нужна ли и куда идёт.
- Лимиты: минимальная и максимальная сумма сделки.
