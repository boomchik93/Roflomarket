# contracts

Protobuf-контракт между gateway и engine. Инструмент — `buf`. Транспорт — Connect RPC.

## Правила

- Контракт меняется только обратно совместимо. Номера полей не переиспользуй и не меняй. Удаляемое поле помечай `reserved`.
- Тип существующего поля не меняй. Нужен другой тип — добавь новое поле.
- Денежные значения — `int64` в минимальных единицах. В TypeScript генератор даёт `bigint`.
- Каждый меняющий RPC содержит поле `idempotency_key`.
- Сгенерированный код хранится в репозитории и руками не правится. После правки `.proto` запусти генерацию и закоммить результат. CI проверяет, что генерация не даёт diff.

## Команды

Из `packages/contracts`:

```bash
buf lint
buf breaking --against '../../.git#branch=main,subdir=packages/contracts'
buf generate
```
